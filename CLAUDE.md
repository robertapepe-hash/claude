# Fonte de dados: projetos Home Electronics (Bia Dacache)

Sempre que o pedido envolver os projetos de Home Electronics (Shield, Shield por ASP, Forecast BC Shopee, BPC, Price Point, WBR-HE, KIs Selection, Built In ou o handover da Beatriz Dacache), use como fonte de dados a pasta:

`projetos/bia-dacache/`

Comece sempre por `projetos/bia-dacache/CLAUDE.md`, depois pelo `LEIA-ME.md` e pelo `00-COMECE-AQUI.md` do projeto em questão.

Não busque esses projetos no Google Drive: a pasta do Drive não é acessível a partir desta sessão. A cópia no repositório é a fonte de referência. Para atualizá-la, o usuário envia um novo zip e a pasta é substituída.
